Put your images here: one folder per image, e.g.
  images/ubuntu-noble/image.yaml
  images/ubuntu-noble/base.raw          (type lxd-vm)   or   base.squashfs (type lxd-container)
Get them with `omloader pull ...` / `omloader import ...` inside the loader (see docs/INSTALL.md section 5),
or copy a prepared folder here. Example image.yaml: examples/ubuntu-24.04/image.yaml
